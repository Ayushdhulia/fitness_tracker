# FitTrack - Premium Fitness Tracking Application

A realistic, highly attractive, and feature-rich fitness application designed to help you transform your body and health.

## Features
- **Smart Dashboard:** Personalized health metrics (BMI, Calories, Hydration).
- **Custom Diet Charts:** Tailored meal plans based on your fitness goals (Weight Loss, Muscle Gain, Maintenance).
- **Exercise Library:** body-part specific routines with instructions and difficulty levels.
- **Hydration Tracker:** Stay on top of your water intake with an interactive logger.
- **Secure Authentication:** JWT-based login and registration.
- **Responsive Design:** Stunning UI/UX built with Tailwind CSS and Glassmorphism effects.

## Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, Lucide Icons, Axios, React Router.
- **Backend:** Node.js, Express, PostgreSQL, Sequelize ORM, JWT, Bcrypt.

## Getting Started

### Prerequisites
- Node.js installed.
- PostgreSQL installed and running.

### 1. Setup Backend
1. Navigate to the `backend` folder:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Update `.env` with your PostgreSQL credentials.
4. Start the server (it will automatically sync the DB and seed exercises):
   ```bash
   npm start
   ```

### 2. Setup Frontend
1. Navigate to the `frontend` folder:
   ```bash

   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
